1. SYSTEM ARCHITECTURE & FILE STRUCTURE
--------------------------------------------------------------------------------
The project is a standalone, lightweight, zero-dependency client-side botanical 
catalogue and field reference application.

Directory Layout:
plantCatalogue/
├── index.html                   # Core web application (UI, styles, catalogue data, interactive JS)
├── images/                      # Field photography archive (43 JPEG specimens)
│   ├── 20261011_142425.jpg
│   ├── ...
│   └── 20261011_150138.jpg
└── plant_catalogue_documentation.txt  # Companion architecture and specification documentation

Key Technologies:
- Markup: Semantic HTML5 structure.
- Styling: Tailwind CSS via CDN with modern responsive card grids and glassmorphic badges.
- Typography: Google Inter font family.
- Logic: Vanilla JavaScript ES6+ (reactive search filter, multi-photo carousel controls).
- Hosting: Fully compatible with GitHub Pages and local filesystem viewing.

3. FUNCTIONALITY & INTERACTION DESIGN
--------------------------------------------------------------------------------
- Real-Time Live Search: Dynamically filters cards matching common name, botanical name, or family.
- Photo Carousels: Entries with multiple field photos have slide navigation buttons, dot indicators, and a counter.
- Image Error Handling: Gracefully falls back if any local image file is temporarily missing.
- Responsive Design: Adapts cleanly from single-column mobile view to 3-column desktop grid.

4. EXECUTION & DEPLOYMENT INSTRUCTIONS
--------------------------------------------------------------------------------
A. Running Locally:
   Simply double-click or open `index.html` in any web browser:
   $ open /Users/karn/Programming/plantCatalogue/index.html
   Or serve with Python / Node:
   $ python3 -m http.server 8000 (accessible at http://localhost:8000)

B. Git & GitHub Setup (https://github.com/karnj22/plantCatalogue):
   1. Initialize local git repository:
      $ cd /Users/karn/Programming/plantCatalogue
      $ git init
   2. Link to remote GitHub repository:
      $ git remote add origin https://github.com/karnj22/plantCatalogue.git
   3. Stage and commit all files:
      $ git add .
      $ git commit -m "feat: complete plant catalogue with verified botanical identifications and index.html"
   4. Push to GitHub:
      $ git branch -M main
      $ git push -u origin main
